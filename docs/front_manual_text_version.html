1

ログインする

システムを開き、社員番号とパスワードを入れて「ログイン」を押します。

※ 初めての方・忘れた方は業務管理課へ。パスワードは左メニューの「パスワード変更」で変えられます。

2

お知らせが届いたら「回覧申請する」を押す

業務管理課が請求書を登録すると、メールまたはLINE WORKSでお知らせが届きます。

ログインすると、最初の画面に 📥 対応が必要な請求書があります と出ます。 📎請求書 で中身を見て、回覧申請する を押します。

3

申請の画面で、空いている所を入れる

マンション・請求書・回覧先（①②③）は自動で入っています。確認して、支払先を選びます。

支払先あなたが入れるもの
管理組合勘定科目（10文字まで　例：小修繕費）と手数料（円／％／なし から選ぶ。円は税抜）
会社（TD）委託内追加で入れるものはありません
会社（TD）元請見積書のPDFを必ず添付（ないと申請できません）

※ 赤い * は必須です。必要なら「備考」や「添付資料」も付けられます。

4

画面のいちばん下の青いボタンを押す

次へ：回覧先の確認 → を押すと送信されます。 上に ✅ 申請を送信しました と出れば完了です。上長へ自動でお知らせが行きます。

5

差し戻されたら、直して「再申請」

最初の画面に ↩ 差し戻し – 再申請が必要です と、差し戻し理由が出ます。

再申請する → 理由どおりに直す → 「再申請理由・修正内容」を書く → ↩ 再申請する

🔎 進み具合を見たいとき

  • 左メニューの「申請一覧・検索」で、自分の申請の状態（回覧中／完了／差し戻し）が見られます。
  • 申請を開くと、いま誰のところにあるか（回覧ルート）が分かります。

💡 困ったときは

  • マンションの担当者が違う → 業務管理課へ連絡してください。
  • 請求書を間違えて受け取った → 申請せずに業務管理課へ。
  • 画面がおかしい → 一度ログアウトして入り直してください。
わからないことは 業務管理課 までお気軽にどうぞ
