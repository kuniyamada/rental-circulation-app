# A5: ファビコン設定 (SVG + 全ページ適用)

**用途**: ブラウザタブ・ホーム画面・ブックマークに表示されるアイコン

**特徴**:
- SVG形式（軽量・高解像度対応・後から色変更容易）
- コード内で完結（外部ツール不要）
- iOS用の apple-touch-icon も同時対応

---

## 📁 配置するファイル

### 1. `public/static/favicon.svg` (メインファビコン)

64x64 viewBox の SVG。ブラウザタブ用。

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <!-- 背景（角丸スクエア） -->
  <rect width="64" height="64" rx="12" fill="#396999"/>

  <!-- ここにアイコン内容 -->
  <!-- 例: 建物 + チェックマーク -->
  <rect x="14" y="18" width="24" height="34" fill="#FFFFFF"/>
  <!-- 窓 -->
  <rect x="17" y="22" width="4" height="4" fill="#396999"/>
  ...
  <!-- 承認チェック(緑バッジ) -->
  <circle cx="46" cy="46" r="12" fill="#22C55E" stroke="#FFFFFF" stroke-width="2"/>
  <path d="M40 46 L44 50 L52 42" stroke="#FFFFFF" stroke-width="3.5" fill="none" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

### 2. `public/static/apple-touch-icon.svg` (iOS用・180x180)

iOS のホーム画面追加時用。少しパディングを増やしたバージョン。

---

## 📝 HTMLに組み込む

すべてのHTML返却箇所の `<head>` に以下を追加：

```html
<link rel="icon" type="image/svg+xml" href="/static/favicon.svg">
<link rel="apple-touch-icon" href="/static/apple-touch-icon.svg">
<meta name="theme-color" content="#396999">
```

### 適用対象（rental-circulation-appの場合、4箇所）
1. `src/routes/layout.ts` (共通レイアウト・ログイン後全ページ)
2. `src/routes/auth.ts` の `loginPage()`
3. `src/routes/auth.ts` の `changePasswordPage()`
4. `src/index.tsx` (旧ダッシュボード・古い実装が残っている場合)

**共通レイアウト(layout.ts)にだけ入れれば、ほぼ全ページに適用される**が、
**ログイン画面など layout.ts を通らないページには個別に追加**が必要。

## 🎨 追加: /favicon.ico フォールバック

一部のブラウザ・SNSクローラは `/favicon.ico` に自動リクエストを送る。
それをSVGにリダイレクトする：

```typescript
// src/index.tsx
app.get('/favicon.ico', (c) => c.redirect('/static/favicon.svg', 301))
```
