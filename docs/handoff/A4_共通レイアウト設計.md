# A4: 共通レイアウト設計 (layout.ts)

**用途**: 全ページで共通のヘッダー・サイドバー・フッター（ボトムナビ）を持たせる。

**メリット**:
- ページごとにHTML全体を書かなくてよい（DRY）
- レイアウト変更が1ファイルで済む
- サイドバー/ボトムナビの現在ページハイライトも自動化

---

## 🎯 全体構造

```typescript
// src/routes/layout.ts
export function layout(title: string, content: string, user: any): string {
  return `<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>${title} - 送金依頼管理システム</title>
  <link rel="icon" type="image/svg+xml" href="/static/favicon.svg">
  <link rel="apple-touch-icon" href="/static/apple-touch-icon.svg">
  <meta name="theme-color" content="#396999">
  <script src="https://cdn.tailwindcss.com"></script>
  <style>
    .sidebar-item { @apply flex items-center gap-3 px-4 py-2.5 rounded-lg text-sm text-gray-600 hover:bg-[#EEF4FA] hover:text-[#396999] transition cursor-pointer; }
    .sidebar-item.active { @apply bg-[#EEF4FA] text-[#396999] font-semibold; }
    .bottom-nav-item { @apply flex flex-col items-center justify-center gap-0.5 text-gray-500 py-2 px-3 rounded-lg transition; }
    .bottom-nav-item.active { @apply text-[#396999]; }
  </style>
</head>
<body class="bg-gray-50 min-h-screen">
  <!-- ヘッダー -->
  <header class="bg-white border-b border-gray-200 fixed top-0 left-0 right-0 z-50">
    <!-- ロゴ + ハンバーガー(スマホ) + ユーザー名 + ログアウト -->
  </header>

  <div class="flex pt-14">
    <!-- サイドバー (PC:常時表示 / スマホ:ドロワー) -->
    <aside id="sidebar" class="w-64 bg-white border-r border-gray-200 fixed left-0 top-14 bottom-0 overflow-y-auto z-40 transform -translate-x-full lg:translate-x-0 transition-transform duration-200">
      <nav class="p-3 space-y-1">
        <a href="/" class="sidebar-item ${title === 'ダッシュボード' ? 'active' : ''}">🏠 ダッシュボード</a>
        <a href="/requests" class="sidebar-item ${title === '依頼一覧' ? 'active' : ''}">📄 依頼一覧</a>
        <!-- ... 権限に応じて条件表示 ... -->
        ${user.is_admin ? `<div class="pt-3">管理者メニュー</div>` : ''}
      </nav>
    </aside>

    <!-- モバイル用オーバーレイ -->
    <div id="overlay" onclick="toggleSidebar()" class="fixed inset-0 bg-black bg-opacity-40 z-30 hidden lg:hidden"></div>

    <!-- メインコンテンツ -->
    <main class="flex-1 lg:ml-64 p-3 sm:p-4 lg:p-6 pb-20 lg:pb-6">
      <div class="max-w-6xl mx-auto">
        <h1 class="text-lg sm:text-xl font-bold text-gray-800 mb-4 sm:mb-6">${title}</h1>
        ${content}
      </div>
    </main>
  </div>

  <!-- スマホ用ボトムナビ -->
  <nav class="lg:hidden fixed bottom-0 left-0 right-0 bg-white border-t border-gray-200 z-50">
    <!-- ... -->
  </nav>

  <!-- 共通モーダル（ファイルプレビュー等） -->
  <div id="savedFilePreviewModal" class="hidden fixed inset-0 bg-black/70 z-[60] items-center justify-center">
    <!-- ... -->
  </div>

  <script>
    function toggleSidebar() {
      document.getElementById('sidebar').classList.toggle('-translate-x-full')
      document.getElementById('overlay').classList.toggle('hidden')
    }
    // ファイルプレビュー機能等...
  </script>
</body>
</html>`
}
```

## 📝 各ページからの使い方

```typescript
requests.get('/', async (c) => {
  const user = await getSessionUser(...)

  const content = `
    <div class="bg-white rounded-xl shadow-sm p-5">
      <table>...</table>
    </div>
  `

  return c.html(layout('依頼一覧', content, user))
})
```

たったこれだけで、ヘッダー・サイドバー・ボトムナビが自動でつきます。

## 🎨 デザインシステム（Tailwind + カラーパレット）

**メインカラー**: `#396999`（濃紺ブルー・信頼感）
**サブカラー**: `#AECBE5`（薄ブルー）
**背景色**: `#EEF4FA`（極薄ブルー）
**アクセント（承認）**: `#22C55E`（緑）
**アクセント（差し戻し）**: `orange-500`
**アクセント（否決）**: `red-500`

```
角丸: rounded-xl / rounded-lg
シャドウ: shadow-sm / shadow-md
ボーダー: border border-gray-100 / border-gray-200
フォント: 日本語Web安全フォント (system-ui, sans-serif)
```

## 🎯 サイドバーのアクティブ判定パターン

`title` 引数を使って現在ページを判定：
```typescript
${title === '依頼一覧' ? 'active' : ''}                       // 完全一致
${title.includes('マンション') ? 'active' : ''}               // 部分一致
${title === 'ダッシュボード' || title === 'ホーム' ? 'active' : ''}  // OR
```

## 📱 レスポンシブ設計

| ブレークポイント | 挙動 |
|---|---|
| `lg` (1024px+) | サイドバー常時表示、メイン `ml-64` |
| `md` (768px) | サイドバー隠れる、ハンバーガー表示 |
| `sm` (640px) | ボトムナビ表示 |
