### 2. コードファイル抽出パッケージ — `code-package/`

そのままコピーして使えるファイル群。ドメイン名（rental→送金依頼）だけ書き換えて流用可能。

### 3. AIディベロッパー向け指示プロンプト — `AI_DEVELOPER_PROMPT.md`

送金依頼システムを開発中のAIに、そのままコピペで渡せる長文プロンプト。
このプロンプト1つで、AIが引き継ぎ資料を読んで実装を進められる。

---

## 🚀 使い方（推奨手順）

### ステップ1: AIディベロッパーに全部渡す

1. このパッケージ全体を送金依頼システムの開発環境に配置（`docs/` 配下推奨）
2. **`AI_DEVELOPER_PROMPT.md`** を開いて、その中身を送金依頼開発中のAIに投げる
3. AIが自動的に必要な資料を読んで実装を進めます

### ステップ2: 必要なノウハウだけ選ぶ場合

送金依頼システムに必要なノウハウだけを`docs/handoff/`から抜粋してAIに指示する形も可能。
特に **A1 (Drive自動保存)** は既にメニューだけあるとのことなので、A1から先に実装するのが最短ルート。

### ステップ3: 動作確認

各ノウハウ資料の末尾に「動作確認手順」があるので、それに沿って確認。

## 💡 引き継ぎ時のTips

1. **フォルダ構成は同じでOK**: `src/routes/*` `src/lib/*` `migrations/*` の3層構造で運用中
2. **ドメイン名だけ置換**: 「マンション」「申請」「請求書」→「物件」「依頼」「送金依頼」等
3. **DBスキーマの流用**: `applications` テーブル構造はほぼそのまま「requests」等に流用可能
4. **Cloudflare Secretは新規発行**: システムごとに専用のOAuthクライアント/Secretを発行（横展開ガイド§7参照）
