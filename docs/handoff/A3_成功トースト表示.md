# A3: 成功トースト表示 (URLクエリ経由 + 自動除去)

**用途**: 送信ボタン → 一覧画面へリダイレクト → 「✅ 送信しました」トースト表示 → 5秒後に自動消去

**特徴**:
- URLクエリで情報を渡すシンプルな実装（サーバー側 or KVでの状態管理不要）
- リロードで再表示されないよう URL からクエリを自動除去
- 手動 × ボタンで即消去可能

---

## 📝 実装（サーバー側 = 一覧画面Handler）

```typescript
requests.get('/', async (c) => {
  // ...

  // トースト表示用のクエリを取得
  const createdReqNumber = c.req.query('created') || ''

  // HTMLエスケープ
  const safeCreatedNum = createdReqNumber.replace(/[<>&"']/g, (ch) =>
    ({ '<': '&lt;', '>': '&gt;', '&': '&amp;', '"': '&quot;', "'": '&#39;' }[ch] as string)
  )

  const content = `
    ${createdReqNumber ? `
    <!-- 送信完了トースト（数秒後に自動で消える） -->
    <div id="createdToast"
      class="fixed top-20 left-1/2 -translate-x-1/2 z-[70] bg-white border-2 border-emerald-400 shadow-xl rounded-xl px-5 py-3 flex items-center gap-3 max-w-md w-[92%] sm:w-auto transition-opacity duration-500">
      <div class="w-9 h-9 bg-emerald-500 rounded-full flex items-center justify-center flex-shrink-0">
        <svg class="w-5 h-5 text-white" fill="none" stroke="currentColor" viewBox="0 0 24 24">
          <path stroke-linecap="round" stroke-linejoin="round" stroke-width="3" d="M5 13l4 4L19 7"/>
        </svg>
      </div>
      <div class="flex-1 min-w-0">
        <p class="text-sm font-bold text-gray-800">送金依頼を送信しました</p>
        <p class="text-xs text-gray-500 truncate">依頼番号：${safeCreatedNum}（承認者への通知は数秒以内に送信されます）</p>
      </div>
      <button type="button" onclick="document.getElementById('createdToast')?.remove()"
        class="text-gray-400 hover:text-gray-600 text-xl leading-none px-1">×</button>
    </div>
    <script>
      // 5秒後にフェードアウト、5.5秒後にDOM削除 + URLからパラメータ除去
      (function(){
        setTimeout(function(){
          const t = document.getElementById('createdToast')
          if (t) t.style.opacity = '0'
        }, 5000)
        setTimeout(function(){
          const t = document.getElementById('createdToast')
          if (t) t.remove()
          try {
            const url = new URL(window.location.href)
            url.searchParams.delete('created')
            window.history.replaceState({}, '', url.toString())
          } catch(e){}
        }, 5500)
      })()
    </script>
    ` : ''}

    <!-- 通常の一覧HTML -->
    ...
  `

  return c.html(layout('依頼一覧', content, user))
})
```

## 📝 実装（送信側 = POST Handler）

```typescript
requests.post('/', async (c) => {
  // ... DB保存 ...
  const reqNumber = 'REQ-20260918-3408'  // 生成した依頼番号

  // 通知はバックグラウンドで（A2参照）
  runInBackground(c, async () => {
    await sendNotification(...)
  })

  // 一覧画面へリダイレクト + クエリでトースト表示
  return c.redirect(`/requests?created=${encodeURIComponent(reqNumber)}`)
})
```

## 💡 なぜURLクエリ方式？

- サーバー側で状態を持たなくて済む（KV/セッションストレージ不要）
- リロードすると `?created=REQ-xxx` がURLに残るが、JSで自動除去するため2度目は表示されない
- ブラウザバックしても表示されない（history.replaceStateで書き換え済み）
- POST → GET のリダイレクトで自然に情報を渡せる（POST-Redirect-GET パターン）

---

## 🔍 動作確認

1. 新規送金依頼を作成 → 「送信」ボタン
2. 一覧画面に遷移した瞬間、画面上部に緑バナーが表示される
3. 5秒後、バナーがフェードアウト
4. アドレスバーから `?created=REQ-xxx` が消えている
5. リロードしても、バナーは表示されない
