# B3: 差し戻し / 否決 / 保留 / 再申請 の処理

**用途**: 承認フローの副次的な処理（承認以外のアクション全部）

---

## 🎯 4つのアクションの違い

| アクション | 動作 | 依頼のstatus | 再申請可能？ | ワンショット/やり取り |
|---|---|---|---|---|
| **承認 (approve)** | 次の承認者へ or 完了 | circulating→completed | - | ワンショット |
| **差し戻し (return)** | 依頼者に戻す。修正して再申請してもらう | circulating→returned | ✅ **修正して再申請** | ワンショット |
| **否決 (reject)** | 依頼を却下。二度と承認されない | circulating→rejected | ✅ 新規申請として再申請 | ワンショット |
| **保留 (hold)** | 承認者から依頼者へ質問。回答を待つ | circulating→on_hold | - | ✨**双方向やり取り** |

---

## 📝 差し戻し (return)

## 📝 否決 (reject)

差し戻しとほぼ同じ構造だが、`status = "rejected"` にする。
再申請時は元の依頼を参照しつつ全項目編集可能。

---

## 📝 保留 (hold) と 回答 (answer)

保留は「承認者が質問して依頼者が答える」という双方向やり取り：

```typescript
// 承認者が保留にする
} else if (action === 'hold') {
  await db.prepare(
    'UPDATE circulation_steps SET status = "on_hold", action_comment = ?, acted_at = datetime("now") WHERE id = ?'
  ).bind(comment, stepId).run()
  await db.prepare('UPDATE applications SET status = "on_hold" WHERE id = ?').bind(id).run()
  runInBackground(c, async () => { await sendNotification(db, 'on_hold', ...) })
}
```

```typescript
// 依頼者が回答する
requests.post('/:id/answer/:stepId', async (c) => {
  await db.prepare(
    'UPDATE circulation_steps SET hold_answer = ?, status = "pending", acted_at = datetime("now") WHERE id = ?'
  ).bind(body.answer, stepId).run()
  await db.prepare('UPDATE applications SET status = "circulating" WHERE id = ?').bind(id).run()

  runInBackground(c, async () => {
    await sendNotification(db, 'answered', step.reviewer_id, {...})
  })
  return c.redirect(`/requests/${id}`)
})
```

**画面**: 依頼者側に「回答を入力」フォームを表示 → 送信で承認者に通知が戻る。

## 📝 再申請 (resubmit)

差し戻し/否決から、元の依頼をコピー＆編集して新規依頼として登録：

```typescript
requests.post('/:id/resubmit', async (c) => {
  const orig = await db.prepare(
    'SELECT * FROM applications WHERE id = ? AND applicant_id = ? AND (status = "rejected" OR status = "returned")'
  ).bind(id, user.uid).first() as any
  if (!orig) return c.redirect(`/requests/${id}`)

  const body = await c.req.parseBody({ all: true }) as any
  const reapplyReason = body.reapply_reason || null
  const isReturned = orig.status === 'returned'

  // 編集後の値（未入力なら元申請の値を継承）
  const editedTitle = body.title || orig.title
  const editedAmount = body.amount ? parseInt(body.amount) : orig.amount
  // ... 全項目

  const newNumber = generateRequestNumber()
  const result = await db.prepare(`
    INSERT INTO applications (
      application_number, title, applicant_id, amount, ..., status, current_step,
      resubmit_count, original_application_id,
      returned_reason, reapply_reason, returned_from_step, returned_by_id, is_test
    ) VALUES (?, ?, ?, ?, ..., 'circulating', 1, ?, ?, ?, ?, ?, ?, ?)
  `).bind(
    newNumber, editedTitle, orig.applicant_id, editedAmount, ...,
    (orig.resubmit_count || 0) + 1, orig.id,
    isReturned ? orig.returned_reason : null,
    reapplyReason,
    isReturned ? orig.returned_from_step : null,
    isReturned ? orig.returned_by_id : null,
    orig.is_test || 0
  ).run()
  const newId = result.meta.last_row_id as number

  // 添付ファイル引き継ぎ（B1参照）
  // 回覧ステップ再作成
  await createCirculationSteps(db, newId, user.uid, ...)

  // 通知
  if (isReturned) {
    // 差し戻し再申請: 全承認者に通知
    const steps = await db.prepare('SELECT reviewer_id FROM circulation_steps WHERE application_id = ?').bind(newId).all()
    runInBackground(c, async () => {
      for (const s of steps.results as any[]) {
        await sendNotification(db, 'reapplied', s.reviewer_id, {...})
      }
    })
  } else {
    // 否決からの再申請: Step1のみに通知（新規申請と同じ挙動）
    const firstStep = await db.prepare('SELECT reviewer_id FROM circulation_steps WHERE application_id = ? AND step_number = 1').bind(newId).first() as any
    runInBackground(c, async () => {
      await sendNotification(db, 'review_request', firstStep.reviewer_id, {...})
    })
  }

  return c.redirect(`/requests?created=${encodeURIComponent(newNumber)}`)
})
```

## 🎨 UIパターン

**差し戻し理由をボタンクリック時に必ず入力させる**:
```javascript
function promptComment(e) {
  const action = e.target.value  // 'return' / 'reject' / 'hold'
  const label = { return: '差し戻し理由', reject: '否決理由', hold: '保留理由（質問内容）' }[action]
  const reason = prompt(label + 'を入力してください:')
  if (!reason || !reason.trim()) { e.preventDefault(); return false }
  e.target.form.querySelector('textarea[name="comment"]').value = reason
  return true
}
```
