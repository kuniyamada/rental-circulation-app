# B1: 添付ファイル管理 (R2 + attachments テーブル)

**用途**: 送金依頼に「請求書」「見積書」「領収書」等の複数種類の添付ファイルを紐付ける仕組み

**構成**:
- **R2**: バイナリファイル本体（PDF/画像/Excel/Word）
- **D1 `attachments` テーブル**: ファイルのメタ情報（ファイル種別・元ファイル名・R2キー）

---

## 📁 テーブル設計

```sql
CREATE TABLE IF NOT EXISTS attachments (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  application_id INTEGER NOT NULL,     -- 送金依頼では request_id 等に置換
  file_type TEXT NOT NULL,             -- 種別識別子 例: 'invoice', 'estimate', 'receipt'
  file_name TEXT NOT NULL,             -- 元のファイル名（ユーザーがアップした名前）
  file_key TEXT NOT NULL,              -- R2上のキー（一意）
  uploaded_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (application_id) REFERENCES applications(id)
);
CREATE INDEX IF NOT EXISTS idx_attachments_application_id ON attachments(application_id);
CREATE INDEX IF NOT EXISTS idx_attachments_file_type ON attachments(file_type);
```

## 🎯 file_type の設計例（rental-circulation-app）

| file_type | 表示名 | 用途 |
|---|---|---|
| `invoice1` 〜 `invoice6` | 請求書①〜⑥ | 複数枚アップロード対応 |
| `other1`, `other2` | 添付①〜② | その他資料 |
| `estimate` | 見積書 | 元請時のみ |
| `kumiai_invoice` | 管理組合宛請求書 | 元請セット申請時のみ |

**送金依頼版の例**:
- `invoice` — 請求書
- `receipt` — 領収書
- `contract` — 契約書
- `other1`, `other2` — その他添付

## 📤 アップロード処理（POSTハンドラ内）

```typescript
requests.post('/', async (c) => {
  const body = await c.req.parseBody({ all: true }) as any
  const reqNumber = generateRequestNumber()

  // 1. まず送金依頼レコードを INSERT して ID を得る
  const result = await db.prepare('INSERT INTO requests (...) VALUES (...)').run()
  const reqId = result.meta.last_row_id as number

  // 2. 添付ファイルを1つずつR2にアップロード & attachmentsに記録
  for (const fileKey of ['invoice', 'receipt', 'contract', 'other1', 'other2']) {
    const file = body[fileKey] as File | undefined
    if (file && file.size > 0) {
      const ext = file.name.split('.').pop()
      const r2Key = `attachments/${reqNumber}/${fileKey}.${ext}`

      // R2 に本体保存
      await c.env.R2.put(r2Key, await file.arrayBuffer(), {
        httpMetadata: { contentType: file.type }
      })

      // D1 にメタ情報記録
      await db.prepare(
        'INSERT INTO attachments (application_id, file_type, file_name, file_key) VALUES (?, ?, ?, ?)'
      ).bind(reqId, fileKey, file.name, r2Key).run()
    }
  }

  return c.redirect(`/requests?created=${reqNumber}`)
})
```

## 📥 ダウンロード処理

```typescript
// GET /files/:attachId で attachment_id をキーにR2から返す
app.get('/files/:attachId', async (c) => {
  const attachId = parseInt(c.req.param('attachId'))
  const att = await c.env.DB.prepare(
    'SELECT file_key, file_name FROM attachments WHERE id = ?'
  ).bind(attachId).first() as any

  if (!att) return c.notFound()

  const obj = await c.env.R2.get(att.file_key)
  if (!obj) return c.notFound()

  return new Response(obj.body, {
    headers: {
      'Content-Type': obj.httpMetadata?.contentType || 'application/octet-stream',
      'Content-Disposition': `inline; filename*=UTF-8''${encodeURIComponent(att.file_name)}`
    }
  })
})
```

### プレビュー用JavaScript
```javascript
function handleFilePreview(input, previewBtnId) {
  const btn = document.getElementById(previewBtnId)
  if (input.files && input.files[0]) {
    btn.classList.remove('hidden')
    btn.classList.add('flex')
  } else {
    btn.classList.add('hidden')
    btn.classList.remove('flex')
  }
}

function openFilePreview(input) {
  if (!input.files || !input.files[0]) return
  const file = input.files[0]
  const url = URL.createObjectURL(file)
  window.open(url, '_blank')
}
```

## 💡 応用: 再申請時の添付ファイル引き継ぎ

差し戻された申請の再申請では、新しいファイルが指定されなければ **元申請のR2キーを共有する**：

```typescript
requests.post('/:id/resubmit', async (c) => {
  const origAtts = await db.prepare('SELECT * FROM attachments WHERE application_id = ?').bind(origId).all()
  const origAttMap: Record<string, any> = {}
  for (const att of origAtts.results as any[]) origAttMap[att.file_type] = att

  for (const fileType of ['invoice', 'receipt', 'contract', 'other1', 'other2']) {
    const uploaded = body[fileType] as File | undefined
    if (uploaded && uploaded.size > 0) {
      // 新規アップロード
      const r2Key = `attachments/${newNumber}/${fileType}.${uploaded.name.split('.').pop()}`
      await c.env.R2.put(r2Key, await uploaded.arrayBuffer(), {...})
      await db.prepare('INSERT INTO attachments ...').bind(newId, fileType, uploaded.name, r2Key).run()
    } else if (origAttMap[fileType]) {
      // 元申請から引き継ぎ（file_keyを共有）
      const orig = origAttMap[fileType]
      await db.prepare('INSERT INTO attachments (application_id, file_type, file_name, file_key) VALUES (?, ?, ?, ?)')
        .bind(newId, fileType, orig.file_name, orig.file_key).run()
    }
  }
})
```

**重要**: R2キーを共有することで**ストレージ二重消費を防ぐ**。1つのR2オブジェクトを複数のattachmentレコードから参照する形。

## 🔒 セキュリティ考慮

1. **アクセス制御**: `/files/:attachId` にはセッション認証を必ずかける
2. **サイズ制限**: `parseBody` の際に大きすぎるファイルを弾く
3. **拡張子チェック**: 実行可能ファイル(.exe, .sh, .php等)はサーバー側でも弾く
