# C2: 申請番号の自動採番 (REQ-YYYYMMDD-XXXX形式)

**用途**: 依頼番号を人にも読みやすく、かつ一意にするための採番

**形式例**: `REQ-20260918-3408`
- `REQ` = 依頼(Request)のプレフィックス
- `20260918` = 作成日 (YYYYMMDD JST)
- `3408` = ランダム4桁

**メリット**:
- 見ただけで作成日が分かる
- 同じ日でも重複しづらい（10000通り）
- DB IDと切り離して管理できる（後からIDが変わっても番号は変わらない）

---

## 🎯 実装

```typescript
// src/lib/auth.ts (または src/lib/utils.ts)
export function generateApplicationNumber(): string {
  const now = new Date(Date.now() + 9 * 60 * 60 * 1000)  // JST
  const y = now.getUTCFullYear()
  const m = String(now.getUTCMonth() + 1).padStart(2, '0')
  const d = String(now.getUTCDate()).padStart(2, '0')
  const rand = Math.floor(1000 + Math.random() * 9000)  // 1000〜9999
  return `REQ-${y}${m}${d}-${rand}`
}
```

**送金依頼版のプレフィックス例**:
- `SNK-YYYYMMDD-XXXX` (SouKin)
- `PAY-YYYYMMDD-XXXX` (Payment)
- `IRA-YYYYMMDD-XXXX` (Irai)

---

## 📁 DBカラム

```sql
CREATE TABLE applications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  application_number TEXT UNIQUE NOT NULL,   -- ⭐ UNIQUE制約が重要
  ...
);
```

`UNIQUE` 制約により、万一同じ番号が生成されても INSERT が失敗するので事故防止になる。

---

## 💡 UNIQUE衝突時のリトライ

Math.random ベースなので同じ日に10000件を超えると理論上衝突する。念のためリトライ処理：

```typescript
async function generateUniqueApplicationNumber(db: D1Database): Promise<string> {
  for (let attempt = 0; attempt < 10; attempt++) {
    const num = generateApplicationNumber()
    const existing = await db.prepare('SELECT id FROM applications WHERE application_number = ?').bind(num).first()
    if (!existing) return num
  }
  // 10回失敗したらランダム桁を増やす
  return `${generateApplicationNumber()}-${Math.floor(Math.random() * 10000)}`
}
```
