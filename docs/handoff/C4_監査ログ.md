# C4: 監査ログ (誰がいつ何をしたか記録)

**用途**: 業務系システム必須の「操作記録」。誰がいつ、どの依頼に、どんな操作をしたかを保存

**特徴**:
- 依頼のライフサイクル全体を追跡可能
- notification_logs でメール送信履歴も残す
- 監査時に「あの承認は本当にあの人がしたのか」証明できる

---

## 📁 テーブル設計

### audit_logs テーブル（汎用監査）
```sql
CREATE TABLE IF NOT EXISTS audit_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,                        -- 操作した人 (未ログイン操作なら NULL)
  action TEXT NOT NULL,                   -- 'login' / 'create_request' / 'approve' / 'delete' / etc
  target_type TEXT,                       -- 'application' / 'user' / 'mansion' / etc
  target_id INTEGER,                      -- 対象のID
  detail TEXT,                            -- 変更内容 (JSON文字列 or 説明文)
  ip_address TEXT,                        -- IPアドレス
  user_agent TEXT,                        -- ブラウザ情報
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_audit_user ON audit_logs(user_id);
CREATE INDEX idx_audit_target ON audit_logs(target_type, target_id);
CREATE INDEX idx_audit_created ON audit_logs(created_at DESC);
```

## 🎯 ヘルパー関数

```typescript
// src/lib/audit.ts
export async function logAudit(
  db: D1Database,
  c: any,
  action: string,
  target: { type: string; id: number } | null,
  detail?: any
): Promise<void> {
  const user = c.get('user' as any) as any
  const ip = c.req.header('CF-Connecting-IP') || c.req.header('X-Forwarded-For') || ''
  const ua = c.req.header('User-Agent') || ''

  await db.prepare(`
    INSERT INTO audit_logs (user_id, action, target_type, target_id, detail, ip_address, user_agent)
    VALUES (?, ?, ?, ?, ?, ?, ?)
  `).bind(
    user?.uid || null,
    action,
    target?.type || null,
    target?.id || null,
    detail ? JSON.stringify(detail) : null,
    ip,
    ua
  ).run()
}
```

## 📝 使用例

```typescript
// ログイン
auth.post('/login', async (c) => {
  // ... 認証処理 ...
  await logAudit(c.env.DB, c, 'login', { type: 'user', id: user.id })
})

// 依頼作成
requests.post('/', async (c) => {
  // ... INSERT処理 ...
  await logAudit(c.env.DB, c, 'create_request', { type: 'application', id: reqId }, {
    amount, payee_id, title
  })
})

// 承認
requests.post('/:id/review/:stepId', async (c) => {
  // ... 承認処理 ...
  await logAudit(c.env.DB, c, `${action}_request`, { type: 'application', id: Number(id) }, {
    step: step.step_number,
    comment
  })
})

// 削除
admin.post('/users/:id/delete', async (c) => {
  // ... 削除処理 ...
  await logAudit(c.env.DB, c, 'delete_user', { type: 'user', id: Number(id) })
})
```

## 🎛 管理画面 (/admin/audit)

```typescript
admin.get('/audit', async (c) => {
  const targetType = c.req.query('type') || ''
  const targetId = c.req.query('id') || ''

  let sql = `
    SELECT al.*, u.name as user_name, u.employee_number
    FROM audit_logs al
    LEFT JOIN users u ON al.user_id = u.id
    WHERE 1=1
  `
  const params: any[] = []
  if (targetType) { sql += ' AND al.target_type = ?'; params.push(targetType) }
  if (targetId) { sql += ' AND al.target_id = ?'; params.push(targetId) }
  sql += ' ORDER BY al.created_at DESC LIMIT 200'

  const logs = await db.prepare(sql).bind(...params).all()

  const content = `
    <table class="w-full text-sm">
      <thead><tr><th>日時</th><th>ユーザー</th><th>操作</th><th>対象</th><th>詳細</th><th>IP</th></tr></thead>
      <tbody>
        ${(logs.results as any[]).map(l => `
          <tr>
            <td>${formatD1DateTime(l.created_at)}</td>
            <td>${l.user_name || '-'} <span class="text-xs text-gray-500">${l.employee_number || ''}</span></td>
            <td><span class="px-2 py-0.5 bg-blue-100 rounded">${l.action}</span></td>
            <td>${l.target_type ? `${l.target_type}#${l.target_id}` : '-'}</td>
            <td class="text-xs">${l.detail ? escHtml(l.detail).slice(0, 100) : ''}</td>
            <td class="text-xs text-gray-500">${l.ip_address || ''}</td>
          </tr>
        `).join('')}
      </tbody>
    </table>
  `
  return c.html(layout('監査ログ', content, user))
})
```

## 💡 保存期間の設計

- 監査ログは業務系では **1年以上** 保存が望ましい
- 古いログは月次で別テーブル (audit_logs_archive) に移動 or 削除
- R2 に圧縮アーカイブする方法も
